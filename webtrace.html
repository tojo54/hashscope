ADVANCED FORENSIC WORKFLOWS

Built-In Viewers, Deleted Recovery & Acquisition Modes

Recover Deleted History (SQLite WAL, Freelist & VSS)

Even after a user clears browser history, HashScope WebTrace scans unallocated SQLite B-Tree freelist pages, uncommitted Write-Ahead Log (-wal) frames, Rollback Journals, and Windows Volume Shadow Copies (VSS) to carve purged URLs and timestamps with exact hexadecimal byte offsets.

Cached Web Page Viewer, JSON Viewer & Apple PLIST Viewer

Reconstruct cached HTML pages in a sandboxed offline viewer, browse cached images in the built-in visual gallery, and inspect raw Bookmarks, Preferences, sessionstore.jsonlz4, and Apple binary bplist00 files without third-party tools.

4 Evidence Acquisition Modes

1. Local Live System (bypasses OS locks), 2. External Drive / Mounted Image (E01/VHDX), 3. Remote Network PC (\\Host\C$), and 4. Manual File Loader.

Time Zone & DST Configuration

Converts WebKit (1601), PRTime (1970), Cocoa CoreData (2001), and Windows FILETIME timestamps into any target IANA Time Zone with automatic Daylight Saving Time rules.

Court-Admissible Report Builder

Build formatted PDF / Printable HTML Reports or export filtered records to XLSX, CSV, and JSON complete with SHA-256 and MD5 Chain-of-Custody tables.
