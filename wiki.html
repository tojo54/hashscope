Forensic Browser History & Artifact Locations Encyclopedia

Default file system paths scanned automatically by HashScope WebTrace across Windows, macOS, and Linux:

Google Chrome & Chromium

  • Windows: %LOCALAPPDATA%\Google\Chrome\User Data\<Profile>\
  • macOS: ~/Library/Application Support/Google/Chrome/<Profile>/
  • Linux: ~/.config/google-chrome/<Profile>/
  • Artifacts: History, Network/Cookies, Bookmarks, Login Data, Web Data, Favicons, Top Sites, Sessions/Session_*, Preferences, Cache/Cache_Data/

Microsoft Edge

  • Windows: %LOCALAPPDATA%\Microsoft\Edge\User Data\<Profile>\
  • macOS: ~/Library/Application Support/Microsoft Edge/<Profile>/
  • Linux: ~/.config/microsoft-edge/<Profile>/

Mozilla Firefox & Tor Browser

  • Windows: %APPDATA%\Mozilla\Firefox\Profiles\*.default-release\
  • macOS: ~/Library/Application Support/Firefox/Profiles/*.default-release/
  • Linux: ~/.mozilla/firefox/*.default-release/
  • Tor Browser: Desktop\Tor Browser\Browser\TorBrowser\Data\Browser\profile.default\
  • Artifacts: places.sqlite, cookies.sqlite, formhistory.sqlite, favicons.sqlite, logins.json, sessionstore.jsonlz4, prefs.js, permissions.sqlite, cache2/entries/

Apple Safari

  • macOS: ~/Library/Safari/History.db, Bookmarks.plist, Downloads.plist, LastSession.plist, PerSitePreferences.db, ~/Library/Cookies/Cookies.binarycookies

Microsoft Internet Explorer 10 / 11 & Legacy Edge

  • Windows ESENT Database: %LOCALAPPDATA%\Microsoft\Windows\WebCache\WebCacheV01.dat, %LOCALAPPDATA%\Microsoft\Windows\INetCache\, %USERPROFILE%\Favorites\

Deleted History Recovery & Unallocated SQLite Carving

When a suspect clears browsing history or deletes individual visits, HashScope WebTrace recovers deleted artifacts from four independent forensic layers:

  1. SQLite Unallocated Freelist & Cell Freeblocks: Scans raw B-Tree leaf pages (0x0D) and unallocated freelist pages inside History, places.sqlite, Cookies, and Web Data for purged URL records and adjacent 64-bit timestamps, reporting exact hexadecimal byte offsets (0x...).
  2. SQLite Write-Ahead Logs (.sqlite-wal) & Rollback Journals (-journal): Carves historical WAL frames that still contain pre-deletion snapshots of rows deleted prior to checkpointing.
  3. Windows Volume Shadow Copies (VSS): Enumerates \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy* snapshots to recover historical browser profiles wiped by privacy cleaners.
  4. Residual Cross-Artifact Correlation: Extracts lingering domain and URL evidence from Favicons (icon_mapping), Cache_Data, and Shortcuts databases even after primary history tables are vacuumed.

4 Acquisition Modes & Court-Admissible Report Builder

  • 1. Local Live Triage: Enumerates all installed browsers on the live workstation, safely bypassing OS file locks via read-only shadow staging.
  • 2. External Drive / Mounted Forensic Image: Point at any mounted drive or forensic image (E01, VHDX, RAW) to scan all user profiles across Windows, macOS, or Linux partitions.
  • 3. Remote Network Computer Capture: Acquire browser artifacts over administrative SMB shares (\\TARGET-PC\C$\Users\...).
  • 4. Manual Artifact File Loader: Inspect standalone SQLite, JSON, .plist, sessionstore.jsonlz4, or WebCacheV01.dat files.
  • Court-Admissible Exports: Generate Printable PDF / Forensic HTML Reports, Excel Workbooks (.xlsx), CSV (.csv), and JSON Evidence Packages (.json) complete with SHA-256 and MD5 Chain-of-Custody manifests.
